# StudyOS Publishing Package

Este pacote prepara a documentação para Apple App Store e Google Play.

## Campos que precisam de dados reais
Todos os marcados com **[PREENCHER]** devem ser completados somente quando a empresa, domínio, contas, provedores e configuração final estiverem definidos.

## Não publicar antes de
1. Validar a política de privacidade contra os serviços realmente usados.
2. Confirmar os dados do Data Safety/Privacy disclosures.
3. Publicar a Política de Privacidade em URL pública.
4. Testar exclusão de conta e dados.
5. Gerar e testar builds finais em dispositivos físicos.
6. Revisar juridicamente os documentos aplicáveis.
