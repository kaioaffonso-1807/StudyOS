# Segurança e Privacidade

## Controles implementados/preparados
- autenticação
- autorização
- RLS no modelo de dados
- rate limiting
- headers de segurança
- request IDs
- health/readiness
- exportação de dados
- exclusão de dados
- CodeQL
- Dependabot
- Dependency Review

## Segredos
Nunca armazenar no repositório:
- chaves de IA
- chaves secretas de pagamento
- tokens de deploy
- credenciais administrativas

## Produção
Antes do lançamento, validar os serviços reais e preencher os documentos legais com os dados efetivamente tratados.
