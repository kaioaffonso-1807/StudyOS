# Jornada do Usuário

## 1. Descoberta
Usuário encontra o StudyOS pela loja, indicação ou site.

## 2. Onboarding
Cria uma conta e entende a proposta do produto.

## 3. Diagnóstico
Realiza o placement test para estabelecer um ponto inicial.

## 4. Personalização
O sistema cria experiências adequadas ao perfil do estudante.

## 5. Prática diária
O usuário pratica por texto, lições e voz.

## 6. Feedback
Erros e progresso influenciam futuras atividades.

## 7. Evolução
O estudante acompanha sua trajetória e retorna para continuar.

## 8. Monetização
Quando atinge necessidades além do plano gratuito, pode migrar para Pro.
